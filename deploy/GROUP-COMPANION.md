# 牛牛精灵群友模式

借鉴 [大肥鱼 AstrBot 群友方案](https://github.com/whyever77/dafeiyu-astrbot)
和 [大肥鱼 QQ bot](https://github.com/nanbengxian-cyber/dafeiyu-qq-bot) 的交流分层思路，
在现有 nanobot 通道中独立实现“上下文 → 是否接话 → 模型与只读工具 → 输出检查”。
不复制上游代码和人格，不迁移框架，不安装额外插件集、本地大模型或付费语音服务。

## 使用

- `牛牛，今晚怎么练急停？`：昵称唤醒；原有 @、回复机器人和 `#ai` 仍有效。
- `牛牛精灵，看看这张图` 加图片：沿用现有 DeepSeek 原生多模态；也可回复图片并 @机器人。
- 回复一条**同群语音**并 @机器人：QQ 原生 `fetch_ptt_text` 转写后，用文字回答。
  支持客户端能够发送的“回复机器人 / @机器人 + 语音”消息；普通语音不触发。
- `#记住 <内容>`、`#记忆`、`#忘记 <编号>`：沿用可查看、可删除的群共享长期记忆。
  群友模式按当前问题选择最多六条相关记录，不会自动把普通聊天写入长期记忆。
- `#ai 清空`：清除共享对话和临时聊天片段，不清除手动长期记忆，也不重置主动接话配额。

角色和身份使用真实消息携带的群号、QQ，昵称只作不可信资料；战绩、胜负、牛币和在线状态
仍由现有只读工具查询，不能把历史对话当实时数据，也不能执行群成员写入的所谓系统指令。

## 边界和资源

主动接话只由**新群消息**触发，无定时问候、无后台轮询模型。十分钟内至少三条消息且有两个
不同发言人，出现求助类问题后才考虑接话；对他人的回复、@他人、命令和媒体消息不自动接话。
默认每群每 30 分钟至多一次、每小时至多两次、滚动 24 小时至多八次；失败或被丢弃的
尝试也消耗配额。生成期间有新消息、内容重复、模型认为不适合或回答超过 160 字时静默丢弃。
明确提问的长回答不会按这个 160 字上限截断，仍按原逻辑完整分段发送。

内存中每群最多八条文字片段，每条最多 220 字，有效期十分钟，最多 32 群。
临时片段不落盘；磁盘 `/data/runtime/companion-rate.json` 只保存配额时间戳，不含聊天正文。
配额文件损坏时停止主动接话，但保留明确唤醒。新增功能无独立常驻进程或模型。

文字和图片继续共用原有 20 个 AI 并发配额；原生语音转写单独串行，忙时明确提示稍后重试，
转写请求有 25 秒保护。转写失败不下载音频、不调用第三方 ASR、不执行转写中的机器人命令。
当前**语音合成关闭**：即使以后 QQ 音色恢复，也不会自动改为语音回复。

## 配置

在已有 `config/config.json` 的 `channels.pwcs2` 中仅合并这些字段，不替换其他配置：

```json
{
  "aiCompanionEnabled": true,
  "aiCompanionGroups": ["你的目标群号"],
  "aiCompanionProactiveEnabled": true,
  "aiCompanionMinIntervalSeconds": 1800,
  "aiCompanionHourlyLimit": 2,
  "aiCompanionDailyLimit": 8,
  "aiVoiceEnabled": true,
  "aiVoiceReplyEnabled": false
}
```

仓库示例默认关闭，生产仅启用既有主群白名单。关闭 `aiCompanionProactiveEnabled` 可单独停止
主动接话；关闭 `aiCompanionEnabled` 则回到原来的 @ / 回复 / `#ai` 入口。
语音转写由 `aiVoiceEnabled` 单独控制，仍受已有群白名单和私聊开关约束。

只更新 bot 镜像并重建 bot；不重启 NapCat、TeamSpeak 或网络服务，不恢复竞猜和搬运，
不改变每日 23:30 总结、校园与新加坡分流或“内存异常只告警、不自动重启 QQ”的策略。
验证时区分 AI API 可用、网关运行和 QQ 账号在线：前两者成功不代表 QQ 已登录。
实际语音转写仍需账号在线后，用一条真实语音验收；本地模拟测试不能替代这一步。

## 临时静默

`automaticQuietUntil` 可设为带时区的 ISO 时间。到期前后台播报、被动梗图和主动接话
不发群；命令、@、回复机器人和昵称唤醒仍正常。到期后自然恢复，无需定时重启或重启 QQ。
对局仍记录记忆、挑战和牛币奖励，但不生成图片锐评或新增自动 Demo 任务。
`messageReplayIgnoreBefore` 可丢弃截止时间以前的旧入站消息，防止重新登录时重放旧命令。
取消旧补发时只推进比赛通知游标、取消通知/视频待办，保留绑定、战绩、钱包和现有文件；
操作前通过 SQLite backup 做私密快照，不删除数据库或媒体目录。
